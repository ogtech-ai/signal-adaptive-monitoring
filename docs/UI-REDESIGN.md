# 持續監測單頁

暖白、深墨、cobalt 訊號與 amber 模擬事件。主圖占桌機約 2/3，右側呈現真實樣本／持續漂移／冷卻閘門。手機改為單欄；主要操作至少 44px，重要文字 12–13px，局部表格可鍵盤/觸控捲動。

主要體驗是自動流入與實際模型生命週期，不是手動注入。固定週期＋噪音、稀疏尖峰/缺值、工況漂移自動發生；手動測試收進次要展開區。先看分布與門檻，再看候選/驗收/版本。相對 active 的漂移與不可變初始漂移同時保留，初始基準警示不因模型更新消失。

訓練畫面只顯示真實 queued / CPU training / 候選已完成數，fit 很快時直接展示實際毫秒與歷史，不延長成假的動畫。候選通過歷史驗收但回退後會標為非 Active；版本標示是否仍保留模型或僅 metadata。匯出提供策略與有限資料/metadata，不冒稱已保存權重或永久 registry。
