# 監測工作區互動設計

單頁聚焦「資料 → 參考基準 → 測試變化」，沒有登入、空白 sidebar 或多頁導覽。

- 暖白與深墨文字；cobalt 呈現量測，amber 只標示合成修改與警報區間。圖形由真實資料與模型結果計算，沒有把參考圖當背景。
- 資料載入即顯示預覽，尚未建模時明確區分預選參考與已算出的基準門檻。建模後設定列收合，保留來源、範圍與重新設定入口；首次在手機直接展開參考設定與建立按鈕，不讓使用者面對大片不可操作控制。
- 主訊號圖占桌機主要面積，含真實時間／單位、固定 ±4 MAD 區帶、缺值中斷、合成區間與 hover 數值。回放控制位於圖表正下方。
- 右側直接提供尖峰／漂移／缺值三個測試動作；尖峰明示功率 +2 kW、電流 +8.7 A 同步變化；校正核准、凍結狀態、回退、目前版本與長期偏移集中在同一區。
- 比較圖聚焦固定／校正 MAD；以虛線讓重合曲線仍能辨識。IsolationForest 保留真實計算與事件警報，不混用不同量綱的 raw score。警報減少與覆蓋率皆保留判讀限制。
- 事件偏離分數明示 MAD，與訊號 kW 分開；手機動作旁顯示當前 MAD 摘要與比較定位入口。事件依連續區間聚合，可篩選合成／背景、滑鼠點選或鍵盤 Enter 定位。背景警報沒有故障真值，不杜撰已恢復或故障原因。
- 模型、來源與重現證據折疊；主畫面不堆 JSON。匯出保留完整參數、來源資料、版本、合成標記與控制時間軸。
- 來源或參考改變會清除模型與核准；分析中禁用相關動作，來源切換會取消並忽略過期回應。CSV 無時間欄時標記未知時間，不套用 UCI 的一分鐘時間軸。
- 支援 1440／768／390px，無橫向溢位；手機主要控制觸控高度 44px、可見 focus、原生表單與 reduced-motion 設定。

固定 median/MAD、IsolationForest 與受控中心校正方法未改；這不是 TTT，也未宣稱已連接記錄器或在 G520 實測。
